# xtt

I am building a compact open-source portfolio around agent tooling, MCP workflows, prompt evaluation, repository understanding, and lightweight data tools.

## Start Here

If you only have 2 minutes, start with these:

- [skillgrade](https://github.com/xtt1997/skillgrade)  
  Lint and scan Agent Skills before they become someone else's install problem.

- [mcpdock](https://github.com/xtt1997/mcpdock)  
  Keep one local source of truth for MCP servers and export it to multiple clients.

- [csvlens-web](https://github.com/xtt1997/csvlens-web)  
  Inspect a CSV in the browser and understand its shape in seconds.

## Current Focus

| Project | What it does | Stack |
| --- | --- | --- |
| [skillgrade](https://github.com/xtt1997/skillgrade) | Trust layer for Agent Skills: lint, scan, doctor, and CI summaries | TypeScript |
| [mcpdock](https://github.com/xtt1997/mcpdock) | Local MCP server manager and exporter for Codex, Claude Desktop, and Cursor | TypeScript |
| [promptdiff](https://github.com/xtt1997/promptdiff) | Zero-dependency CLI for diffing prompt and eval output snapshots | Python |
| [repocanon](https://github.com/xtt1997/repocanon) | Zero-dependency CLI for turning repositories into compact Markdown summaries | Python |
| [feishu-mcp-starter](https://github.com/xtt1997/feishu-mcp-starter) | Minimal Feishu MCP starter kit with env doctor and config renderer | Python |
| [csvlens-web](https://github.com/xtt1997/csvlens-web) | Lightweight browser CSV inspector with column summaries and preview table | JavaScript |

## Operating Principle

Every project is public, tracked for stars and forks, and iterated based on real adoption signals instead of keeping dead side-projects alive forever.

I refresh the portfolio ranking every 2 days and keep improving the top 2 projects instead of spreading effort evenly across dead repos.
