# xtt

I am building a small open-source portfolio around agent tooling, MCP workflows, prompt evaluation, repository understanding, and lightweight data tools.

## Current Focus

- [skillgrade](https://github.com/xtt1997/skillgrade)  
  Trust layer for Agent Skills: lint, scan, doctor, and CI summaries.

- [mcpdock](https://github.com/xtt1997/mcpdock)  
  Local MCP server manager and exporter for Codex, Claude Desktop, and Cursor.

- [promptdiff](https://github.com/xtt1997/promptdiff)  
  Zero-dependency CLI for diffing prompt and eval output snapshots.

- [repocanon](https://github.com/xtt1997/repocanon)  
  Zero-dependency CLI for turning repositories into compact Markdown summaries.

- [feishu-mcp-starter](https://github.com/xtt1997/feishu-mcp-starter)  
  Minimal Feishu MCP starter kit with env doctor and config renderer.

- [csvlens-web](https://github.com/xtt1997/csvlens-web)  
  Lightweight browser CSV inspector with column summaries and preview table.

## Operating Principle

Every project is public, tracked for stars and forks, and iterated based on real adoption signals instead of keeping dead side-projects alive forever.
